# What can you buy?

Игра про траты виртуального состояния. Все 56 позиций из списка включены в каталог.

## Запуск

Нужен Node.js 20 или новее. Установка пакетов не требуется.

Открой терминал в этой папке:

```sh
npm start
```

Сайт: http://localhost:3000

Другой порт: `PORT=3001 npm start`. Для остановки нажми Ctrl+C.

## Что умеет

- Стартовые бюджеты: $1 млн, $1 млрд, $100 млрд, $1 трлн.
- Покупка от 1 до 9 999 единиц за раз; баланс не может стать отрицательным.
- Коллекция, продажа одной позиции или всего количества по полной игровой цене.
- Поиск, категории и сортировка по цене / купленным позициям.
- Информация о каждой позиции и источник её изображения.
- Короткая политика конфиденциальности внизу страницы: отсутствие сбора личных данных и аналитики, локальное сохранение прогресса, игровая природа магазина и валюты.
- Автосохранение в localStorage и синхронизация между вкладками одного браузера.
- Мобильная версия, клавиатурная навигация, учёт уменьшенной анимации.

## Файлы

`index.html` — разметка. `styles.css` — оформление. `app.js` — игра. `catalog.js` — названия, цены, категории. `photos.js` — фотографии и примечания. `server.mjs` — локальный статический сервер на встроенных модулях Node.js.

Нет фреймворков, базы данных, сторонних JavaScript-зависимостей, оплаты, аккаунтов и аналитики. Фотографии и шрифт находятся локально. Изменить цену или описание можно в `catalog.js`.

## Контент

Все цены условные, в долларах США. Для будущих / несуществующих объектов использованы реальные фото близких моделей, научных объектов или локаций с пояснениями. «Tesla Capsule» представлена как BOXABL Casita; SE и Performante — разные версии Lamborghini Urus, в каталоге выбрана SE. «Построить станцию» трактуется как орбитальная станция. Услуги и будущие проекты иллюстрируются реальными тематическими фотографиями.

Авторы, источники и лицензии: `assets/CREDITS.md`. Официальные изображения продуктов сохраняют права соответствующих правообладателей; этот локальный игровой проект не заявляет связи с брендами. Лицензия шрифта Inter: `assets/FONT-LICENSE.txt`.

## Проверка

```sh
npm run check
```

Прогресс относится к конкретному браузеру и адресу сайта. Новая игра очищает коллекцию после подтверждения. При запрете localStorage игра продолжает работать, но прогресс не сохраняется.
